# 🚀 AI Smart Assistant (Next.js & Gemini)

A modern, responsive, and high-performance AI Chatbot built to demonstrate seamless integration between modern frontend frameworks and Google's powerful Gemini LLM. 

This project is tailored for businesses looking to implement custom AI solutions, automated customer support, or smart content generators.

## ✨ Key Features
- **Real-time AI Responses:** Powered by Google's Gemini 1.5 Flash for rapid and accurate content generation.
- **Modern UI/UX:** Clean, minimal, and responsive design built with Tailwind CSS and Lucide Icons.
- **Markdown Support:** Perfectly formats AI outputs, including code blocks, lists, and bold text.
- **Optimized Performance:** Uses Next.js App Router and serverless API routes for fast execution.

## 🛠️ Tech Stack
- **Frontend:** React, Next.js (App Router), Tailwind CSS
- **AI Integration:** Google Generative AI SDK (`@google/generative-ai`)
- **Icons & Formatting:** Lucide React, React-Markdown
